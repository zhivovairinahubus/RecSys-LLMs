Graph-Based Recommendations with Personalized PageRank

HW6 assignment: build a user–movie bipartite graph, propagate personalized PageRank with TensorFlow.js, and compare popularity, global PageRank, PPR and matrix factorization on a shared evaluation cohort.

The graph is built from positive training interactions only; an unobserved rating is missing data, not a zero.
